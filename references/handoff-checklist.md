# Human developer handoff checklist

- Repository URL, visibility, branch, last known good commit and backup verification level.
- How to obtain prerequisites and run/build/test/deploy; distinguish verified commands from inferred instructions.
- Source map: entry points, screens, models, services, persistence, content/assets, integrations and owners.
- Secrets/environment variable names and secure provisioning procedure, never values.
- Known bugs, unfinished features, limitations, design constraints and operational risks.
- Key decisions/trade-offs and links to relevant commits/ADRs/PRs.
- Release and rollback instructions only if verified; unresolved access/credentials and next steps.
- Explicit list of checks not performed.
